# Overview

The Red Box is an entity found in multiple locations in Northern Oregon and Southern Washington. It manifests as a simple red box with no notable features or markings on any side.

![](@assets/anomalies/eid-998/1771162939056-redbox.png)

It has manifested in the following locations:

- A forest floor
- The rooftop of ████ █████
- Locker A54 in the ███ stadium
